# AP Browser (ApostolProject Browser)

**Русский** | [English](README.en.md) | [中文](README.zh-CN.md) | [Español](README.es.md) | [Deutsch](README.de.md) | [Français](README.fr.md)

Браузер нового поколения с упором на приватность: **браузер + рабочая среда + база знаний + AI** в одном приложении. Не Electron — построен на **Tauri 2 / Rust** с нативными вкладками WebView2. Windows 10/11.

## Возможности

- **Вкладки** — нативные вкладки WebView2 в одном окне-шелле: спящие вкладки, drag & drop, закрепление 📌, таб-папки (группы), разделение экрана, фавиконы и реальные заголовки, сворачиваемая боковая панель, контекст-меню
- **Приватность к реальному трафику** — встроенный фильтрующий прокси режет трекеры/рекламу/малварь по доменам; HTTPS-only апгрейд, контроль файлов cookie и Referer, WebRTC-изоляция, DoH/DNS, внешние прокси-цепочки (до 3 хопов), исключения для сайтов, живая статистика блокировок
- **Заметки** — Markdown-редактор с превью, картинками (включая SVG), рисованием от руки, подмножеством LaTeX (`$...$`), папками, экспортом `.md`
- **Граф знаний** — бесконечный холст на настоящем `<canvas>` с физической раскладкой, карточками заметок, связями, undo/redo, экспортом PNG с содержимым блоков
- **Воркспейсы и профили** — изолированные профили по папкам хранилища, наборы вкладок на каждый воркспейс, анонимный режим
- **Сейф** — менеджер паролей: шифрование AES-256-GCM, выведение ключа Argon2id, импорт/экспорт CSV
- **Закладки и история** — на SQLite, история по профилям, папки закладок, букмарклеты `javascript:`, подсказки в омнибоксе
- **Палитра команд** — Ctrl+K, поиск на русском и английском
- **AI чат** — провайдеры, совместимые с OpenAI, и локальная Ollama
- **Загрузки** — свой движок с настоящей отменой, повторной закачкой и прогресс-баром со скоростью и графиком
- **Локализация** — русский и английский интерфейсы
- Тёмная/светлая темы, умная тёмная тема сайтов, кастомизация (`.apbtheme`), прозрачность/стекло окна, обучающий тур

## Планы

1. Полноценный рантайм расширений (content scripts по маскам)
2. Локализация за пределами RU/EN
3. Кастомный инсталлятор (полный контроль установки на Rust)

## Технологии

| Слой | Технология |
|---|---|
| Бэкенд | Rust workspace (`crates/*`), Tauri v2, wry/WebView2 |
| Фронтенд | Vanilla HTML/CSS/JS — без бандлера, без npm, без фреймворков |
| Данные | `%APPDATA%/dev.apb.browser/` (SQLite, Markdown, JSON) |

Фронтенд вшивается в бинарник при сборке (`frontendDist = "../ui"`).

## Сборка из исходников

Требования: [Rust](https://rustup.rs) (stable, тулчейн MSVC), WebView2 Runtime (предустановлен в Windows 10/11).

```powershell
cd apps/desktop/src-tauri
cargo build
# запуск дебаг-сборки:
../../target/debug/apb-desktop.exe
```

## Структура проекта

```
apps/desktop/
  src-tauri/        Rust-бэкенд (shell, pages, доменные команды cmd/*)
  ui/               Фронтенд шелла (index.html + js-модули, грузятся по порядку)
crates/             Доменные крейты: notes, canvas, vault, privacy,
                    network, history, bookmarks, profiles, extensions, ai...
```
