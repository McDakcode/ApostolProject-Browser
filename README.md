# AP Browser (ApostolProject Browser)

**Русский** | [English](README.en.md) | [中文](README.zh-CN.md) | [Español](README.es.md) | [Deutsch](README.de.md) | [Français](README.fr.md)

**APB** — приватный десктопный браузер, который объединяет в одном приложении:

- полноценный браузер с нативными вкладками,
- рабочее пространство (воркспейсы и профили),
- базу знаний (заметки + граф связей),
- менеджер паролей,
- AI-ассистента.

Без Electron. Построен на **Tauri 2 + Rust** и нативных вкладках **WebView2**.

> Стабильная девелоперская сборка **v0.2.7**. Пока только Windows 10/11.

---

## Зачем это нужно

Большинство «приватных» браузеров — это либо форк Chromium/Firefox с набором расширений, либо тонкая обёртка. APB идёт другим путём:

- **Изоляция по-настоящему.** Каждый профиль — отдельная папка хранилища. Закладки, история, заметки, настройки приватности, сеть и сейф не пересекаются.
- **Свой прокси-слой.** Локальный HTTP-прокси умеет блокировать трекеры/рекламу/малварь по доменам, переписывать заголовки, строить цепочки (HTTP/SOCKS5) и показывать статистику блокировок.
- **База знаний внутри браузера.** Markdown-заметки с картинками, рисованием, LaTeX и связанный с ними интерактивный граф.
- **Минимум лишнего.** Vanilla JS на фронте, никакого npm/React/Vue. Бинарник относительно лёгкий.

## Возможности

### Браузер и вкладки
- Нативные вкладки WebView2 в одном окне-шелле
- Спящие вкладки, drag & drop, закрепление, таб-папки (группы), разделение экрана (split view)
- Фавиконы и реальные заголовки страниц, сворачиваемая боковая панель, контекст-меню вкладок
- Воркспейсы — наборы вкладок с быстрым переключением
- Перехват загрузок (свой движок: отмена, повтор, прогресс со скоростью) и восстановление сессии

### Приватность и сеть
- Уровни приватности + аварийный режим (panic button)
- Локальный фильтрующий прокси: блокировка трекеров/рекламы/малвари по доменам и живая статистика
- DNS / DoH, пользовательские DNS-серверы, HTTPS-only, контроль cookies и Referer, WebRTC-изоляция, цепочки прокси
- Переопределения правил для отдельных сайтов
- Аудит настроек (DNS, прокси, расширения, AI, сейф)

### Заметки и граф знаний
- Markdown-редактор с превью
- Картинки (включая SVG), рисование от руки, подмножество LaTeX (`$...$`)
- Папки и экспорт в `.md`
- Бесконечный холст с физической раскладкой
- Карточки заметок, связи, undo/redo, экспорт в PNG

### Профили и данные
- Полностью изолированные профили (включая анонимный)
- История и закладки на SQLite (папки закладок, букмарклеты `javascript:`)
- Подсказки в омнибоксе: история + закладки + продолжения доменов + поиск — всё локально, без внешних suggest-серверов

### Сейф (Vault)
- Менеджер паролей
- AES-256-GCM + Argon2id
- Импорт / экспорт CSV
- Генерация паролей

### Прочее
- AI-чат (OpenAI-совместимые провайдеры + локальная Ollama)
- Палитра команд (Ctrl+K) — поиск на русском и английском
- Тёмная / светлая темы, умная тёмная тема сайтов, кастомизация (`.apbtheme`), прозрачное окно / эффект стекла
- Локализация интерфейса: русский и английский
- Обучающий тур для новых пользователей
- Система расширений: рантайм v1 (content scripts по маскам URL), UI управления пока скрыт

## Технологии

| Слой     | Стек |
|----------|------|
| Бэкенд   | Rust workspace (`crates/*`), Tauri 2, wry / WebView2 |
| Фронтенд | Vanilla HTML / CSS / JS — без бандлера, без npm, без фреймворков |
| Данные   | `%APPDATA%/dev.apb.browser/` (SQLite, Markdown, JSON) |
| Сборка   | Фронтенд вшивается в бинарник (`frontendDist = "../ui"`) |

### Структура репозитория

```
apps/desktop/
  src-tauri/        Rust-бэкенд (shell, pages, доменные команды cmd/*)
  ui/               Фронтенд шелла (index.html + js-модули)
crates/             Доменные крейты:
                    notes, vault, privacy, network, history,
                    bookmarks, profiles, extensions, ai ...
```

## Сборка из исходников

**Требования:**
- [Rust](https://rustup.rs) (stable, тулчейн MSVC)
- WebView2 Runtime (уже предустановлен в Windows 10/11)

```powershell
cd apps/desktop/src-tauri
cargo build

# запуск дебаг-сборки:
../../target/debug/apb-desktop.exe
```

Релизная сборка:

```powershell
cargo build --release
```

## Планы

1. Полный рантайм расширений v2 — content scripts по маскам URL уже исполняются (v1), дальше: UI управления расширениями и более широкий API
2. Локализация интерфейса за пределами RU/EN
3. Кастомный NSIS-инсталлятор (сейчас — стандартный от tauri)
4. Загрузки по закрытым ссылкам: передавать cookies из профиля в движок загрузок
5. DoT (DNS over TLS) — сейчас поддерживаются DoH и пользовательские DNS-серверы
6. Дальнейшая полировка производительности и стабильности вкладок

## Известные ограничения / текущие баги

- **Загрузки за авторизацией.** Свой движок загрузок не передаёт cookies WebView2, поэтому файлы по закрытой ссылке могут падать в «ошибку» (публичные закачки работают).
- **Cookie-политики.** Применяются в момент создания вкладки — после смены политики нужно открыть вкладку заново; `Set-Cookie` в HTTPS-ответах прокси не переписывает.
- **DNS.** DoH и пользовательские DNS-серверы работают; DoT не поддержан. Трафик на LAN/IP-адреса всегда идёт напрямую.
- **Расширения.** Рантайм v1 исполняет content scripts по маскам, но UI управления скрыт, API ограничен.
- **Локализация.** Только русский и английский.
- **LaTeX в заметках.** Поддерживается подмножество (`$...$`, `$$...$$`).
