# AP Browser (ApostolProject Browser)

**Русский** | [English](README.en.md) | [中文](README.zh-CN.md) | [Español](README.es.md) | [Deutsch](README.de.md) | [Français](README.fr.md)

**APB** — приватный десктопный браузер, который объединяет в одном приложении:

- полноценный браузер с нативными вкладками,
- рабочее пространство (воркспейсы и профили),
- базу знаний (заметки + граф связей),
- менеджер паролей,
- AI-ассистента.

Без Electron. Построен на **Tauri 2 + Rust** и нативных вкладках **WebView2**.

> Ранняя стадия разработки (v0.2.x). Пока только Windows.

---

## Зачем это нужно

Большинство «приватных» браузеров — это либо форк Chromium/Firefox с набором расширений, либо тонкая обёртка. APB идёт другим путём:

- **Изоляция по-настоящему.** Каждый профиль — отдельная папка хранилища. Закладки, история, заметки, настройки приватности, сеть и сейф не пересекаются.
- **Свой прокси-слой.** Локальный HTTP-прокси умеет блокировать трекеры, переписывать заголовки, строить цепочки (HTTP/SOCKS5) и показывать статистику блокировок.
- **База знаний внутри браузера.** Markdown-заметки с картинками, рисованием, LaTeX и связанный с ними интерактивный граф.
- **Минимум лишнего.** Vanilla JS на фронте, никакого npm/React/Vue. Бинарник относительно лёгкий.

## Возможности

### Браузер и вкладки
- Нативные вкладки WebView2 в одном окне-шелле
- Спящие вкладки, drag & drop, разделение экрана (split view)
- Фавиконы, сворачиваемая боковая панель
- Воркспейсы — наборы вкладок с быстрым переключением
- Перехват загрузок и восстановление сессии

### Приватность и сеть
- Уровни приватности + аварийный режим (panic button)
- Локальный прокси с блокировкой трекеров и живой статистикой
- DNS / DoH, цепочки прокси
- Переопределения правил для отдельных сайтов
- Аудит настроек (DNS, прокси, расширения, AI, сейф)

### Заметки и граф знаний
- Markdown-редактор с превью
- Картинки, рисование от руки, подмножество LaTeX (`$...$`)
- Папки и экспорт в `.md`
- Бесконечный холст с физической раскладкой
- Карточки заметок, связи, undo/redo, экспорт в PNG

### Профили и данные
- Полностью изолированные профили (включая анонимный)
- История и закладки на SQLite
- Умные подсказки в омнибоксе

### Сейф (Vault)
- Менеджер паролей
- AES-256-GCM + Argon2id
- Импорт / экспорт CSV
- Генерация паролей

### Прочее
- AI-чат (OpenAI-совместимые провайдеры + локальная Ollama)
- Палитра команд (Ctrl+K) — поиск на русском и английском
- Тёмная / светлая тема, кастомизация интерфейса
- Обучающий тур для новых пользователей
- Система расширений (в активной разработке)

## Технологии

| Слой     | Стек |
|----------|------|
| Бэкенд   | Rust workspace (`crates/*`), Tauri 2, wry / WebView2 |
| Фронтенд | Vanilla HTML / CSS / JS — без бандлера, без npm, без фреймворков |
| Данные   | `%APPDATA%/dev.apb.browser/` (SQLite, Markdown, JSON) |
| Сборка   | Фронтенд вшивается в бинарник (`frontendDist = "../ui"`) |

### Структура репозитория

```
apps/desktop/
  src-tauri/        Rust-бэкенд (shell, pages, доменные команды cmd/*)
  ui/               Фронтенд шелла (index.html + js-модули)
crates/             Доменные крейты:
                    notes, vault, privacy, network, history,
                    bookmarks, profiles, extensions, ai ...
```

## Сборка из исходников

**Требования:**
- [Rust](https://rustup.rs) (stable, тулчейн MSVC)
- WebView2 Runtime (уже предустановлен в Windows 10/11)

```powershell
cd apps/desktop/src-tauri
cargo build

# запуск дебаг-сборки:
../../target/debug/apb-desktop.exe
```

Релизная сборка:

```powershell
cargo build --release
```
